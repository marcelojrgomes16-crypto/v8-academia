# V8 Academia

> Sistema de gestao para academia.

## Resumo

Sistema web completo com painel do aluno, professor e administrador.

## Stack

- Next.js 14, React 18, Tailwind CSS
- Prisma ORM, PostgreSQL
- NextAuth v5
- Radix UI, shadcn/ui
