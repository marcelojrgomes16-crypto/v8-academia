# Estoque Distribuidora

> Sistema de gestao de estoque.

## Resumo

Sistema para controle de produtos, entradas e saidas com notificacoes WhatsApp.

## Stack

- Node.js, Express
- PostgreSQL (pg)
- JWT, Twilio
