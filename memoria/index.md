## Como funciona

Esta pasta contem a memoria organizada do OpenCode. Cada arquivo e uma nota com links entre si.

## Estrutura

- **projetos/** - Informacoes sobre cada projeto
- **configuracoes/** - Credenciais, stack, deploy
- **conhecimento/** - Aprendizados, bugs, padroes
- **diario/** - Registro diario
